# Plan

Create a Spec-Driven execution plan in short batches.

Rules:

1. Base the plan on `specs/*.spec.md`.
2. Split work by workstream: Architecture, Integration/Resilience, Observability/Operations.
3. Include acceptance criteria per task.
4. Propose subagent usage for parallelizable tasks.

Output format:
- `Now` (1-3 tasks)
- `Next` (2-4 tasks)
- `Later` (backlog)
- `Verification` (commands and expected evidence)
